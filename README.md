# 임용 스터디

사회과 중등교원임용시험(1차 필기) 준비용 개인 학습 관리 웹앱입니다.
로그인·서버 없이 `index.html` 파일 하나로 동작하고, 기록은 브라우저(localStorage)에만 저장됩니다.

## 주요 기능

- **대시보드**: 시험 D-day와 다가오는 일정, 모의고사용 카운트다운, 공부시간 기록용 타이머, 오늘의 과목별 학습시간, 오늘 공부량, 이번 주 공부시간 그래프, 할 일 체크리스트
- **과목 관리**: 과목별(교육학 / 전공 1교시 / 전공 2교시) 오늘 학습시간, 누적 학습시간과 목표 달성률
- **모의고사**: 과목별 점수 추이 그래프와 회차별 점수 기록

## 사용 방법

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다.
갤럭시 Z 폴드처럼 접고 펴는 화면에 맞춰 레이아웃이 바뀝니다.

## 참고

- 공부 기록은 사용하는 브라우저에만 저장되므로, 다른 기기나 브라우저에서는 보이지 않습니다.
- 브라우저 데이터를 삭제하면 기록도 함께 지워집니다.
- AI(Claude)의 도움을 받아 만들었습니다.
